# Recomp & MMA

Deux implémentations d'une même app de suivi entraînement / nutrition /
poids pendant une recomposition corporelle et une préparation MMA, avec le
même backend Supabase et les mêmes règles UX (tendance en moyenne mobile 7
jours uniquement, jamais le poids brut ; nutrition sans culpabilisation ;
plateau apparent traité comme un signal positif de recomposition, pas une
alerte).

- **`ios-mma-recomp/`** — SwiftUI (iOS 17+), gardée pour référence.
- **`android-mma-recomp/`** — Kotlin / Jetpack Compose, plateforme active.

Chaque dossier a son propre `README.md` avec les instructions de setup.
